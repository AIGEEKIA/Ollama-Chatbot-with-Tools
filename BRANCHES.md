# BRANCHES DU PROJET

## Branches Disponibles :
- **main** : Version complète AVEC outils (calculator, weather, file, search)
- **sans-tools** : Version simplifiée SANS outils (chatbot basique)

## Comment Basculer :
git checkout main        # Version avec outils
git checkout sans-tools  # Version sans outils

## Différences :
- main : Fonctionnalités avancées, outils intégrés
- sans-tools : Chatbot simple, plus léger, plus rapide

## Utilisation :
1. Choisir la branche selon les besoins
2. Démarrer avec : python quick_start.py start
3. Interface : http://localhost:8000
